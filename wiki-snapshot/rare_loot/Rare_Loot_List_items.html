Category:Rare Loot List items

The main article for this category is Looting#Rare_loot

Beginning with Magic of Myth Drannor's release in Update 69, some named items in that expansion and all content released since have been found only as part of a rare loot list. Normally, when a named item drops from a chest with a rare loot list, only some of the potential items and/or Lunar and Solar Gems can spawn - there is only a small chance (about 5% in Myth Drannor and content released before Lamordia, increased to 6% in Lamordia) that a random item or Gem on the rare loot list will drop instead. An item marked as "rare" on its page or on a quest's loot table is on a rare loot list. Every item and Gem on a quest's rare loot list has an equal chance of dropping if the game determines that a rare item will spawn, in the same way that (barring rare exceptions) all standard loot has an equal chance of dropping.

(Lunar and Solar Gems can drop in multiple quests, but if a given type of Gem is marked as rare in one quest, it will always be on the rare loot list in other drop locations. Currently only Solar Gems seem to have the capability to be marked as rare. If a rare Gem drops in a quest that appears in a Saga, that Gem will be a possible drop from the Saga's end reward.) Note: Some Gems are mistakenly marked as rare in some but not all of their drop locations - this is considered a bug, but affected Gems are also listed in the Rare Loot List category.)
